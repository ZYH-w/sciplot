# 简图 SciPlot

一个本地运行的中文科研绘图与数据处理工作台。导入实验数据，计算、平滑或整理数据，选择模板并调整曲线与坐标，导出用于论文和报告的图。

## 启动

**Windows 应用版：**解压 `SciPlot-Windows-x64.zip`，进入 `SciPlot-Windows` 文件夹，双击 `SciPlot.exe`。它在独立应用窗口中运行，无需 Node.js 或本地服务器；请保留同目录 DLL 和配置文件。支持 Windows 10/11 x64，需系统具有 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime，详见[桌面版说明](desktop/README.md)。

**独立网页备用版：双击 [`简图-SciPlot.html`](简图-SciPlot.html)**，用 Microsoft Edge、Chrome 或其他新版 Chromium 浏览器打开即可。绘图、Excel 导入与图片导出的全部代码已经放在这一个 HTML 文件中，完全离线可用，不需要账号或联网下载依赖。请使用浏览器打开，不要用文本编辑器打开。根目录的 `启动简图.bat` 会优先打开已构建的 Windows 应用，否则打开独立网页。

开发者可选择本地服务模式：安装 Node.js 20 或更新版本后，在项目目录运行：

```sh
node server.mjs
```

然后打开 <http://127.0.0.1:4173>。不需要安装 npm 依赖。按 `Ctrl+C` 关闭服务。若端口被占用，可通过 `PORT` 环境变量指定其他端口。

## 使用

1. 导入 Excel（XLSX、XLS、XLSM）、ODS、CSV、TSV、TXT、DAT 或 JSON 数据，也可以粘贴从表格中复制的数据。工作簿可选择工作表；自动识别首行表头，也可以手动指定有无表头。各数据列为数值，空缺值会保留为缺口。
2. 选择绘图模板或图形类型，设置每条曲线的 X/Y 列、名称、颜色、线型、粗细和标记。
3. 修改坐标标题与范围、网格、字体和图例；按需启用局部放大或 X 轴断轴。
4. 导出 SVG 矢量图或高分辨率 PNG。选择 PDF 会打开浏览器打印窗口，请选择“另存为 PDF”，使用横向纸张并关闭页眉页脚。
5. 将项目保存为 JSON，以便重新导入并继续编辑；常用样式可以保存为自定义模板。

## 数据处理

点击工具栏中的「数据处理」，选择 Y 数据列及对应 X 列，然后选择具体方法和参数。面板会显示原始与处理后的统计、曲线预览和计算说明；确认后点击「生成结果列」。

- **统计概览**：有效数与缺失数、均值、中位数、最小/最大值、样本标准差与方差、上下四分位数、均值标准误和均方根；可导出统计 CSV。
- **简单计算**：与常数或另一列逐行加、减、乘、除；Min–max 归一化和 Z-score 标准化。除零或数值溢出结果置空并提示；常量列归一化为 0。
- **平滑与滤波**：提供下表中的 7 种独立方法，可调整窗口、阶数、平滑系数或截止频率。
- **异常值处理**：按 IQR 倍数或 Z-score 阈值识别，选择置空、截到阈值边界或按 X 线性插值。保留数据行与原有缺失值；插值不外推首尾，也不跨越原有缺失 X/Y。
- **缺失值补全**：按实际 X 间距插值内部缺口，必须有两侧有效点；缺失 X 和边缘缺口保持为空。
- **求导与积分**：对严格递增的实际 X 求导，内部使用非均匀三点公式，段端点使用相邻两点单侧差分；梯形积分在每个连续有效段从 0 重新累计。两者均在缺失 X/Y 处断开，不跨缺口计算。

每次处理都追加新数据列，原始列及行数保持不变，结果列名称重复时自动加后缀。可以将结果叠加为新曲线；归一化、求导、积分会改变量纲，选择绘图时会切换到结果曲线，原曲线仍保留。撤销可恢复应用前状态。数据表已经有 100 列时，需要先减少列数或换一份数据，才能追加处理结果。

### 算法与验证

| 方法 | 可选参数 | 边界与缺失值处理 |
| --- | --- | --- |
| 滑动平均 | 奇数窗口 1–101 点 | 居中求均值，边缘缩窗；忽略邻域缺失值，保留中心缺失值 |
| 中值滤波 | 奇数窗口 1–101 点 | 居中取中位数，边缘缩窗；有效邻居为偶数时取中间两值平均 |
| 高斯平滑 | 奇数窗口 1–101 点、σ > 0 | σ 以采样点为单位；对有效邻居重新归一化权重，保留中心缺失值 |
| Savitzky–Golay 平滑 | 奇数窗口 3–101 点、阶数 2–5 且小于窗口 | 使用真实 X 做局部多项式最小二乘；边缘移动拟合窗口，中心缺失值保持为空 |
| 一阶指数低通 EMA | 0 < α ≤ 1 | 输出 = α × 当前值 + (1−α) × 上次输出；每段从首值开始，缺失处重置 |
| 二阶 Butterworth 低通 | 采样率 fs > 0、0 < fc < fs/2 | 保留低频；单向因果滤波，采用首值稳态初始条件，缺失 X/Y 时重置 |
| 二阶 Butterworth 高通 | 采样率 fs > 0、0 < fc < fs/2 | 保留高频；单向因果滤波，每段首个输出为 0，缺失 X/Y 时重置 |

SG 实现以居中、缩放后的真实 X 构造多项式，使用重正交 QR 求解最小二乘，因此也支持严格递增的非均匀 X；这是常规等间距 SG 的局部多项式扩展。拟合会跳过邻域缺失点，可能使用缺口两侧邻居；有效点少于阶数加一或拟合不稳定时结果置空并提示。等间距且无缺失时的边缘行为对照 [SciPy `savgol_filter(mode="interp")`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_filter.html)。

Butterworth 固定二阶、Q = 1/√2，单程截止处幅度为通带的 1/√2，约 −3 dB；单向处理存在相位延迟。它要求连续有效 X 的步长一致，相对误差不超过 0.01%。界面按 X 为秒自动估算 fs；其他时间单位请自行换算并核对 fs、fc。设计与初始化分别参考 [SciPy `butter`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.butter.html) 和 [`lfilter_zi`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.lfilter_zi.html)。

统计只使用有限数值，标准差及方差采用样本分母 n−1（[NumPy `std(ddof=1)` 定义](https://numpy.org/doc/stable/reference/generated/numpy.std.html)），四分位数采用 R7 线性插值（[NumPy `quantile(method="linear")` 定义](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)）。没有有效值时统计显示「—」；少于两个有效值时，样本标准差、方差及均值标准误也显示「—」。

数据处理单元测试覆盖缺失值、边缘、常量列、除零/溢出、非均匀 X、源数据不变及真实滤波响应。另用独立 Python/SciPy 计算进行数值核对：

| 验证项目 | 已测案例与最大绝对误差 |
| --- | --- |
| SG 对照 SciPy | 等间距 X、11 点窗口、2–5 阶，含边缘，与 `savgol_filter(mode="interp")` 最大误差约 3.8×10⁻¹³ |
| SG 非均匀 X 扩展 | 非均匀 X、10⁹ 坐标偏置、缺失点及 2–5 阶多项式保持性，最大误差约 7.2×10⁻¹⁵ |
| Butterworth 对照 SciPy | 低通/高通、fs=100、fc=0.1/5/40，与带稳态初值的 `sosfilt` 最大误差约 5.7×10⁻¹² |
| 求导与积分 | 非均匀三点导数对照 `numpy.gradient`，最大误差小于 10⁻¹¹；梯形积分与 `scipy.integrate.cumulative_trapezoid` 一致 |

这些误差是上述测试数据上的观察结果，不是任意数据和参数下的精度保证。应用运行时使用本地 JavaScript 数值实现，不需要安装 Python 或 SciPy。

导入的数据在当前浏览器内处理，不上传到服务器。当前工作会尝试自动保存在本浏览器的本地存储中；清除浏览器数据、更换浏览器、移动独立 HTML 文件或修改本地服务端口，都可能使原来的记录不可见。部分浏览器会限制本地 HTML 的存储权限，此时请使用“保存项目”下载 JSON 备份；数据导入、绘图与文件导出仍可使用。

单次数据最多 50,000 行、100 列，工作簿文件最多 25 MB。公式采用文件中已保存的计算结果，不会重新计算；加密工作簿需要先解除保护。当前版本聚焦二维绘图与常用数值处理，不包含 Origin 的拟合、假设检验和三维绘图。

## 数据格式

`examples` 文件夹包含可直接导入的示例：

- [`演示数据.xlsx`](examples/演示数据.xlsx)：含“轨迹响应对比”（151 行，时间和三组曲线）与“无表头数据”（5 行、3 列）两张工作表，可体验工作表切换和自动表头识别。
- [`演示数据.csv`](examples/演示数据.csv)：同一份 151 行演示数据，UTF-8 编码。
- [`无表头数据.txt`](examples/无表头数据.txt)：5 行、3 列制表符分隔的纯数字数据，第一行应保留为数据。

推荐将 X 放在第一列，每组 Y 分别放在后续列。例如下面的 CSV 可直接导入或粘贴，导入预览中还能修改 X/Y 列：

```csv
时间(s),实验值,预测值
0,12.5,12.3
1,14.8,14.6
2,13.9,14.1
```

文本文件支持逗号、制表符、分号和空格分隔，支持 UTF-8、GBK 和 UTF-16 编码。JSON 支持二维数组、对象数组和 `{ "columns": [...], "rows": [...] }` 结构。自动表头是对首行内容的判断，导入前请查看识别结果；纯数字表头可手动选择“首行是表头”。

图片、PDF 和专有仪器二进制文件不能直接导入。请先从原软件导出为上述表格格式。文件扩展名为 DAT 时，其内容也必须是分隔的文本表格。PNG 导出尺寸以像素为准，界面的 300 DPI 信息用于估算排版宽度，不会增加原始数据的精度。

## 开发验证

构建 Windows x64 应用和 ZIP 发布包（首次构建会从微软官方 NuGet 下载锁定的 WebView2 SDK）：

```powershell
powershell -ExecutionPolicy Bypass -File desktop/build-windows.ps1
```

输出位于 `release/SciPlot-Windows/SciPlot.exe` 与 `release/SciPlot-Windows-x64.zip`。脚本会先重建独立 HTML，再作为资源内嵌进 EXE；最终使用者无需 Node.js。发布包附有 Microsoft WebView2 和 SheetJS 的第三方许可证，未为本项目源代码额外声明开放许可证。

修改源文件后，重新生成零安装独立版：

```sh
node build-standalone.mjs
```

脚本仅使用 Node.js 内置模块和项目内已有资源，无需安装或联网下载构建工具。它检查模块依赖和语法，并将 CSS、图标、SheetJS、许可证与应用代码内嵌为根目录的 `简图-SciPlot.html`。

```sh
node --test *.test.mjs
```

前端使用原生 JavaScript 和 SVG。Excel 读取使用随项目分发的 SheetJS Community Edition 0.20.3，无需联网加载依赖；许可证见 `assets/SHEETJS-LICENSE.txt`。库下载自 [SheetJS 官方 CDN](https://cdn.sheetjs.com/)，用法遵循[官方浏览器文档](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)。`server.mjs` 仅绑定本机地址，并且只提供应用公开文件。
