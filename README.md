# 简图 SciPlot 2.0

一个面向工程实验、时间序列和模型对比的本地中文科研绘图工作台。从工作表编辑、数值处理、拟合与信号分析，到图形元素编辑、误差带、多子图和按毫米尺寸导出，覆盖常见实验论文的出图流程。Windows 应用与独立网页使用同一套本地计算引擎。

## 启动

**Windows 2.0 应用版：**解压 `SciPlot-Windows-v2-x64.zip`，进入 `SciPlot-Windows-v2` 文件夹，双击 `SciPlot.exe`。它在独立应用窗口中运行，无需 Node.js 或本地服务器；请保留同目录 DLL 和配置文件。支持 Windows 10/11 x64，需系统具有 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime，详见[桌面版说明](desktop/README.md)。2.0 使用独立发布目录，可与旧版文件并存。

**独立网页备用版：双击 [`简图-SciPlot.html`](简图-SciPlot.html)**，用 Microsoft Edge、Chrome 或其他新版 Chromium 浏览器打开即可。绘图、Excel 导入与图片导出的全部代码已经放在这一个 HTML 文件中，完全离线可用，不需要账号或联网下载依赖。请使用浏览器打开，不要用文本编辑器打开。根目录的 `启动简图.bat` 会优先打开已构建的 Windows 应用，否则打开独立网页。

开发者可选择本地服务模式：安装 Node.js 20 或更新版本后，在项目目录运行：

```sh
node server.mjs
```

然后打开 <http://127.0.0.1:4173>。不需要安装 npm 依赖。按 `Ctrl+C` 关闭服务。若端口被占用，可通过 `PORT` 环境变量指定其他端口。

## 使用

1. 导入 Excel（XLSX、XLS、XLSM）、ODS、CSV、TSV、TXT、DAT 或 JSON 数据，也可以粘贴从表格中复制的数据。工作簿可选择工作表；自动识别首行表头，也可以手动指定有无表头。各数据列为数值，空缺值会保留为缺口。
2. 在「数据工作表」查看全部行列、修改单元格和列名、粘贴区域或排序；使用「数据处理」整理数值，使用「科研分析」进行拟合、模型对比、频谱、相关或重复测量分析。
3. 选择绘图模板或图形类型，设置各曲线的 X/Y 列。点击图中的曲线、坐标、标题、图例或标注，直接进入对应的「图形编辑器」设置。
4. 按需配置左右 Y 轴、误差条/带、局部放大、X 轴断轴和多子图；确定画布毫米尺寸、字号与输出 DPI，再导出 SVG、PNG、TIFF 或打印 PDF。
5. 对列名相同的一组文件使用「批量套图」，统一输出 ZIP。将当前项目保存为 JSON，以便重新导入并继续编辑；常用图形样式可以保存为自定义模板。

## 工作表与图形编辑

「数据工作表」可分页访问完整数据，每页 25、50 或 100 行；支持直接改值、重命名列、增加/删除行列、按列升降序排序、区域粘贴与选区导出。Shift + 点击可扩展选区，Ctrl + V 粘贴数值区域；单个值可填满选区。排序会同步移动整行，删除列会更新曲线及误差列引用。修改先保存在工作副本中，点击「应用工作表」后一次提交，也可一次撤销；空白单元格表示缺失值。

「图形编辑器」支持下列常用论文图形设置，并在应用前提供预览：

- **坐标与文字**：线性/log₁₀、轴反向、手动范围与主刻度间隔、科学计数、小数位数、刻度方向、左右 Y 轴、字体、字号、颜色和标签偏移。
- **曲线与误差**：独立线型/粗细/透明度、空心或实心标记及间隔、基线填充、对称/不对称 Y 误差及 X 误差；选择误差棒或连续误差带。误差列是非负幅度，不是上下界坐标；误差带要求 X 单调。
- **版面与标注**：单图、上下排列、两列网格，最多 4 个子图；可共享 X 范围并编辑面板编号。支持文字、箭头、直线、矩形、水平/垂直参考线与显著性括号；括号仅显示用户提供的文字，不会执行统计检验。
- **观察细节**：局部放大和 X 轴断轴；坐标和曲线保持实际数值含义。图中元素可点选编辑，鼠标数据光标可辅助查看坐标。图例可设置位置、字号、背景和边框。

## 出版尺寸与批量套图

先设置图宽、图高（mm），再决定字号与 300/600/1200 DPI。单栏 90 mm、双栏 180 mm 等预设仅供起步，具体尺寸、字体和文件格式请遵循目标期刊要求，例如 [Nature 的官方投稿指南](https://www.nature.com/nature/for-authors/initial-submission)。

- **SVG**：保留矢量线条、文字和物理毫米尺寸，可继续编辑。
- **PNG**：像素尺寸按 `mm ÷ 25.4 × DPI` 计算，并写入 pHYs 分辨率元数据。
- **TIFF**：输出不压缩的 24 位 RGB 图像，并写入 X/Y 分辨率与英寸单位标签。
- **PDF**：使用浏览器/桌面运行时的系统打印窗口。选择另存为 PDF，核对纸张尺寸、缩放及页眉页脚；实际打印结果还受系统打印设置影响。

提高 DPI 会增加位图像素数，不会增加原始测量精度。当前位图输出限制为单边 20,000 像素且总计不超过 6,400 万像素，超出时会提示降低尺寸或 DPI。

「批量套图」将当前**可见曲线**的 X/Y 列及误差列按列名匹配到新文件；缺列或没有有效配对的文件会跳过并写入报告。可选择处理工作簿首张或全部工作表，选择自动坐标范围，输出 SVG/PNG/TIFF；自动范围会关闭固定区间的断轴与局部放大。最多选择 20 个文件，单次最多生成 60 张图、150 MB 内容；ZIP 包含图像、对应项目 JSON 和处理报告，当前项目不变。

批量套图复用图形样式及列引用，不会自动重跑之前的拟合或滤波；若模板使用处理结果列，输入文件需已有同名结果列。

## 数据处理

点击工具栏中的「数据处理」，选择 Y 数据列及对应 X 列，然后选择具体方法和参数。面板会显示原始与处理后的统计、曲线预览和计算说明；确认后点击「生成结果列」。

- **统计概览**：有效数与缺失数、均值、中位数、最小/最大值、样本标准差与方差、上下四分位数、均值标准误和均方根；可导出统计 CSV。
- **简单计算**：与常数或另一列逐行加、减、乘、除；Min–max 归一化和 Z-score 标准化。除零或数值溢出结果置空并提示；常量列归一化为 0。
- **平滑与滤波**：提供下表中的 7 种独立方法，可调整窗口、阶数、平滑系数或截止频率。
- **异常值处理**：按 IQR 倍数或 Z-score 阈值识别，选择置空、截到阈值边界或按 X 线性插值。保留数据行与原有缺失值；插值不外推首尾，也不跨越原有缺失 X/Y。
- **缺失值补全**：按实际 X 间距插值内部缺口，必须有两侧有效点；缺失 X 和边缘缺口保持为空。
- **求导与积分**：对严格递增的实际 X 求导，内部使用非均匀三点公式，段端点使用相邻两点单侧差分；梯形积分在每个连续有效段从 0 重新累计。两者均在缺失 X/Y 处断开，不跨缺口计算。

每次处理都追加新数据列，原始列及行数保持不变，结果列名称重复时自动加后缀。可以将结果叠加为新曲线；归一化、求导、积分会改变量纲，选择绘图时会切换到结果曲线，原曲线仍保留。撤销可恢复应用前状态。数据表已经有 100 列时，需要先减少列数或换一份数据，才能追加处理结果。

### 算法与验证

| 方法 | 可选参数 | 边界与缺失值处理 |
| --- | --- | --- |
| 滑动平均 | 奇数窗口 1–101 点 | 居中求均值，边缘缩窗；忽略邻域缺失值，保留中心缺失值 |
| 中值滤波 | 奇数窗口 1–101 点 | 居中取中位数，边缘缩窗；有效邻居为偶数时取中间两值平均 |
| 高斯平滑 | 奇数窗口 1–101 点、σ > 0 | σ 以采样点为单位；对有效邻居重新归一化权重，保留中心缺失值 |
| Savitzky–Golay 平滑 | 奇数窗口 3–101 点、阶数 2–5 且小于窗口 | 使用真实 X 做局部多项式最小二乘；边缘移动拟合窗口，中心缺失值保持为空 |
| 一阶指数低通 EMA | 0 < α ≤ 1 | 输出 = α × 当前值 + (1−α) × 上次输出；每段从首值开始，缺失处重置 |
| 二阶 Butterworth 低通 | 采样率 fs > 0、0 < fc < fs/2 | 保留低频；单向因果滤波，采用首值稳态初始条件，缺失 X/Y 时重置 |
| 二阶 Butterworth 高通 | 采样率 fs > 0、0 < fc < fs/2 | 保留高频；单向因果滤波，每段首个输出为 0，缺失 X/Y 时重置 |

SG 实现以居中、缩放后的真实 X 构造多项式，使用重正交 QR 求解最小二乘，因此也支持严格递增的非均匀 X；这是常规等间距 SG 的局部多项式扩展。拟合会跳过邻域缺失点，可能使用缺口两侧邻居；有效点少于阶数加一或拟合不稳定时结果置空并提示。等间距且无缺失时的边缘行为对照 [SciPy `savgol_filter(mode="interp")`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_filter.html)。

Butterworth 固定二阶、Q = 1/√2，单程截止处幅度为通带的 1/√2，约 −3 dB；单向处理存在相位延迟。它要求连续有效 X 的步长一致，相对误差不超过 0.01%。界面按 X 为秒自动估算 fs；其他时间单位请自行换算并核对 fs、fc。设计与初始化分别参考 [SciPy `butter`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.butter.html) 和 [`lfilter_zi`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.lfilter_zi.html)。

统计只使用有限数值，标准差及方差采用样本分母 n−1（[NumPy `std(ddof=1)` 定义](https://numpy.org/doc/stable/reference/generated/numpy.std.html)），四分位数采用 R7 线性插值（[NumPy `quantile(method="linear")` 定义](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)）。没有有效值时统计显示「—」；少于两个有效值时，样本标准差、方差及均值标准误也显示「—」。

数据处理单元测试覆盖缺失值、边缘、常量列、除零/溢出、非均匀 X、源数据不变及真实滤波响应。另用独立 Python/SciPy 计算进行数值核对：

| 验证项目 | 已测案例与最大绝对误差 |
| --- | --- |
| SG 对照 SciPy | 等间距 X、11 点窗口、2–5 阶，含边缘，与 `savgol_filter(mode="interp")` 最大误差约 3.8×10⁻¹³ |
| SG 非均匀 X 扩展 | 非均匀 X、10⁹ 坐标偏置、缺失点及 2–5 阶多项式保持性，最大误差约 7.2×10⁻¹⁵ |
| Butterworth 对照 SciPy | 低通/高通、fs=100、fc=0.1/5/40，与带稳态初值的 `sosfilt` 最大误差约 5.7×10⁻¹² |
| 求导与积分 | 非均匀三点导数对照 `numpy.gradient`，最大误差小于 10⁻¹¹；梯形积分与 `scipy.integrate.cumulative_trapezoid` 一致 |

这些误差是上述测试数据上的观察结果，不是任意数据和参数下的精度保证。应用运行时使用本地 JavaScript 数值实现，不需要安装 Python 或 SciPy。

## 科研分析

「科研分析」包括下列五组工作流。选择数据列与参数后检查预览、参数表、指标及计算说明；需要保留报告时，在应用结果前点击「导出分析报告」下载 CSV。参数变化后可点击「更新预览」，确认后再生成结果。拟合、对比与重复测量会追加新列；频谱和相关分析创建不同坐标的新数据集，并在应用前明确提示替换当前视图，可用撤销恢复。

### 拟合与参数不确定度

| 模型 | 计算方法 | 输出与适用条件 |
| --- | --- | --- |
| 线性 `y = a + bx` | 无权重最小二乘，居中缩放 X 后重正交 QR | 拟合值、观测−拟合残差、截距/斜率及标准误、均值 95% t 置信带 |
| 2–6 阶多项式 | 对标准化坐标 `z=(x−中心)/尺度` 的多项式做 QR 最小二乘 | 显示 z 方程、各系数及标准误、拟合与残差列；参数对应显示的 z 基底 |
| 指数 `y = A exp(Bx)` | 拟合 `ln(Y)` 对 X 的直线 | 有效 Y 必须为正；A 标准误使用 delta method 近似 |
| 幂律 `y = A x^B` | 拟合 `ln(Y)` 对 `ln(X)` 的直线 | 有效 X/Y 均须为正；不对反变换作偏差修正 |

拟合仅使用有效 X/Y 配对，剔除缺失配对；秩不足或阶数超过数据支持能力时会报错。报告中的 `RMSE=√(SSE/n)`、`R²=1−SSE/SST` 和调整 R²在原始 Y 域计算。指数/幂律的优化目标和参数误差位于对数域，因此不同于直接在原始 Y 域做非线性最小二乘。

参数标准误使用剩余自由度 `n−参数个数`。线性阴影为**回归均值**的双侧 95% Student-t 置信带，不是单个新观测的预测区间；其解释假设误差独立、同方差且近似正态。没有剩余自由度时仍可生成拟合曲线，但标准误、调整 R²及置信带为空。计算定义参照 [NumPy 最小二乘](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)、[SciPy 线性回归标准误](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.mstats.linregress.html) 和 [Student-t 分布](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.t.html)。

### 模型预测对比

选择一列观测数据和最多 12 列预测，按同一行配对，分别报告有效 n、MAE、RMSE、bias、预测 R²和 Pearson r。此处**残差 = 预测−观测**，与拟合页的“观测−拟合”符号相反；bias 是该残差均值。预测 R²使用观测均值作为基准 `1−SSE/SST`，可以为负；观测为常量时 R²不定义，任一列为常量时 Pearson 不定义。

每个模型生成残差及绝对误差列，可选择绘制预测曲线、残差或绝对误差。不同模型独立剔除缺失配对，因此其 n 可能不同；高相关系数不等于预测无偏或数值一致。

### FFT 幅值与功率谱

选择单边幅值谱或功率谱密度 PSD、周期 Hann/矩形窗、是否去均值以及采样率 fs。要求 X 严格递增且等间距，步长相对误差不超过 0.01%；X/Y 均不能有缺失值。不能删除缺失样本后当作连续采样做 FFT，应先按合理方法补齐或选取完整片段。自动 fs 按 X 的单位为秒估算，其他单位需要手动换算。

实现使用实际 radix-2 FFT，将长度补零到下一个 2 的整数次幂。幅值按 `|FFT|/Σw` 校正窗相干增益；PSD 按 `|FFT|²/(fs×Σw²)` 归一化。单边谱仅对内部正频率加倍，DC 和奈奎斯特频率不加倍；若 fs 为 Hz，PSD 单位为 Y²/Hz。归一化定义对照 [SciPy `periodogram`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)，实数 FFT 对照 [NumPy `rfft`](https://numpy.org/doc/stable/reference/generated/numpy.fft.rfft.html)。

频率网格间隔为 `fs/NFFT`，补零只加密网格，不提高由原始记录时长决定的分辨能力。报告提供不含 DC 的主峰频率和 PSD 积分；窗函数会影响泄漏和功率估计。应用后生成频率、幅值、PSD 三列的新数据集。

### 自相关与互相关

选择自相关或两条信号的互相关、最大滞后样本数及 fs；同样要求等距无缺失采样。各信号先减去完整记录的均值，采用 `C(k)=ΣA[i]B[i+k]/√(ΣA²ΣB²)`，分母保持完整信号能量，不按每个滞后的重叠点数重新归一化。自相关的零滞后为 1；常量信号无法定义此归一化。

**正滞后峰表示第二条信号 B 相对 A 延后**，符号与 [SciPy `correlate(B,A)`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.correlate.html) 一致。结果同时保存样本滞后、秒滞后、相关值和重叠样本数；较大滞后的重叠依据较少。报告峰值按相关绝对值选择，自相关会排除零滞后。当前不计算相关显著性或置信区间，相关也不能推断因果。

### 重复测量与误差带

选择至少两列同一条件下的重复测量，逐行生成均值、样本 SD、SEM、95% t 置信区间半宽和实际有效重复数 n；每行独立忽略缺失重复值。可选择 **均值±SD**、**均值±SEM** 或 **均值±95%CI**，并以误差条或阴影带显示：

- `SD` 使用 n−1 分母，表示重复观测的离散程度。
- `SEM=SD/√n` 表示均值标准误。
- `95%CI半宽=t(0.975,n−1)×SEM`；假设重复独立且近似正态。

n<2 的行不计算 SD、SEM 和置信区间，n=0 的行均值也为空。技术重复与独立实验重复的含义由实验设计决定；论文图注需明确误差类型和 n。仅添加显著性括号不会计算或验证 p 值。

### 新增分析的独立数值核对

以独立 Python/NumPy/SciPy 计算作为参考，已测数据上的最大绝对误差如下；这些数值不是对任意输入的精度保证。

| 项目 | 参考与已测最大绝对误差 |
| --- | --- |
| 线性至 6 阶拟合 | 含 10⁶ X 偏置与非零残差，对照 `numpy.linalg.lstsq`；拟合值约 4.89×10⁻¹⁵ |
| 参数标准误 / 线性均值 95% CI | 对照 NumPy 协方差、`scipy.stats.linregress` 与 t 分位数；约 1.36×10⁻¹³ / 7.22×10⁻¹⁶ |
| 单边 PSD / 幅值 | 257 点输入补零至 512 点，Hann/矩形窗，对照 `periodogram` / `rfft`；约 2.67×10⁻¹⁵ / 5.18×10⁻¹⁵ |
| 互相关 | 对照 `scipy.signal.correlate(B,A)` 并按全段能量归一化；约 2.40×10⁻¹⁴ |
| Student-t 95% 分位数 | df=1、2、10、99、1000、49998、50000，对照 `scipy.stats.t.ppf`；约 1.40×10⁻¹¹ |
| 重复测量汇总 | 含逐行缺失，对照 NumPy 样本 SD、SciPy SEM 与 t CI；约 2.49×10⁻¹⁴ |

## 数据保存与功能边界

导入的数据在当前应用内处理，不上传到服务器。当前工作会尝试自动保存在该应用/浏览器的本地存储中；清除应用数据、更换浏览器、移动独立 HTML 文件或修改本地服务端口，都可能使原来的记录不可见。部分浏览器限制本地 HTML 的存储权限，此时请使用「保存项目」下载 JSON 备份；数据导入、绘图与文件导出仍可使用。Windows 桌面版与浏览器版的本地存储彼此独立，通过项目 JSON 交换工作。

单份数据最多 50,000 行、100 列，单图最多 30 条曲线；数据文件最多 25 MB。工作簿公式采用文件中已保存的计算结果，不会重新计算；加密工作簿需先解除保护。

2.0 是对工程实验论文常用流程的扩展，并非全部 Origin 功能的复刻。当前提供上述有限模型的无权重拟合，不包含通用非线性/多峰拟合、加权或约束回归、假设检验、三维绘图和 Origin OPJU 文件解析，也不支持 STFT、小波或通用脚本自动化。

产品流程参考 Origin 的[模板与图形元素编辑](https://www.originlab.com/index.aspx?go=Products%2FOrigin%2FGraphing)、[线性/多项式回归](https://docs.originlab.com/origin-help/linear-polynomial-regression/)及[信号处理工作流](https://docs.originlab.com/labtalk/guide/signal-processing/)。这些参考用于界定常见科研需求，实际可用范围以上述已实现功能和各面板计算说明为准。

## 数据格式

`examples` 文件夹包含可直接导入的示例：

- [`演示数据.xlsx`](examples/演示数据.xlsx)：含“轨迹响应对比”（151 行，时间和三组曲线）与“无表头数据”（5 行、3 列）两张工作表，可体验工作表切换和自动表头识别。
- [`演示数据.csv`](examples/演示数据.csv)：同一份 151 行演示数据，UTF-8 编码。
- [`无表头数据.txt`](examples/无表头数据.txt)：5 行、3 列制表符分隔的纯数字数据，第一行应保留为数据。

推荐将 X 放在第一列，每组 Y 分别放在后续列。例如下面的 CSV 可直接导入或粘贴，导入预览中还能修改 X/Y 列：

```csv
时间(s),实验值,预测值
0,12.5,12.3
1,14.8,14.6
2,13.9,14.1
```

文本文件支持逗号、制表符、分号和空格分隔，支持 UTF-8、GBK 和 UTF-16 编码。JSON 支持二维数组、对象数组和 `{ "columns": [...], "rows": [...] }` 结构。自动表头是对首行内容的判断，导入前请查看识别结果；纯数字表头可手动选择“首行是表头”。

图片、PDF、OPJU 和专有仪器二进制文件不能直接导入。请先从原软件导出为上述表格格式。文件扩展名为 DAT 时，其内容也必须是分隔的文本表格。PNG/TIFF 的像素尺寸和分辨率元数据由毫米尺寸与 DPI 共同确定，SVG 保留物理尺寸；具体导出行为见「出版尺寸与批量套图」。

## 开发验证

构建 Windows x64 应用和 ZIP 发布包（首次构建会从微软官方 NuGet 下载锁定的 WebView2 SDK）：

```powershell
powershell -ExecutionPolicy Bypass -File desktop/build-windows.ps1 -OutputName SciPlot-Windows-v2
```

上述 2.0 构建输出位于 `release/SciPlot-Windows-v2/SciPlot.exe` 与 `release/SciPlot-Windows-v2-x64.zip`。省略 `-OutputName` 时仍使用默认名称，输出到 `release/SciPlot-Windows/SciPlot.exe` 和 `release/SciPlot-Windows-x64.zip`；默认构建命令仍然有效。独立输出目录可以避免覆盖正在运行的旧版 EXE。

脚本会先重建独立 HTML，再作为资源内嵌进 EXE；最终使用者无需 Node.js。发布包附有 Microsoft WebView2 和 SheetJS 的第三方许可证，未为本项目源代码额外声明开放许可证。

修改源文件后，重新生成零安装独立版：

```sh
node build-standalone.mjs
```

脚本仅使用 Node.js 内置模块和项目内已有资源，无需安装或联网下载构建工具。它检查模块依赖和语法，并将 CSS、图标、SheetJS、许可证与应用代码内嵌为根目录的 `简图-SciPlot.html`。

```sh
node --test *.test.mjs
```

前端使用原生 JavaScript 和 SVG。Excel 读取使用随项目分发的 SheetJS Community Edition 0.20.3，无需联网加载依赖；许可证见 `assets/SHEETJS-LICENSE.txt`。库下载自 [SheetJS 官方 CDN](https://cdn.sheetjs.com/)，用法遵循[官方浏览器文档](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)。`server.mjs` 仅绑定本机地址，并且只提供应用公开文件。
